# Raspberry Pi Projects

Projects and deployment files intended to run on Raspberry Pi hardware.

## Projects

- `IMAX_Seat_Tracker/` - Canonical Playwright/Chromium scanner and Tailscale API used by the IMAX Tracker Android app, with synchronous and background-job endpoints.
- `Motion_Camera/` - USB webcam streaming and HC-SR501 motion-triggered five-second recordings from up to two cameras.
- `Radio_Frequency/` - Radio-frequency send and receive utilities.

Each project has its own README with installation, runtime, and troubleshooting instructions.
